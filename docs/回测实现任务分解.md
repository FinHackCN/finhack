# 回测实现任务分解

## 详细实现计划

### 实现优先级

1. **P0 - 核心功能**：EventCenter, TradeCenter, DataCenter基础实现
2. **P1 - 关键功能**：Context管理, Strategy接口, 基础事件循环
3. **P2 - 增强功能**：交易规则, 绩效分析, 报告生成
4. **P3 - 优化功能**：性能优化, 多品种支持, 高级特性

### 依赖关系

```
EventCenter ←→ TradeCenter ←→ DataCenter
    ↓              ↓             ↓
BacktestTrader ←→ Context ←→ Strategy
    ↓              ↓             ↓
Performance ←→ Rules ←→ ConfigManager
```

### 里程碑

- **里程碑1**：完成基础架构，能够运行简单的回测
- **里程碑2**：完成策略接口，能够运行现有策略
- **里程碑3**：完成交易规则和风控，支持复杂交易场景
- **里程碑4**：完成性能分析，生成完整回测报告
- **里程碑5**：完成系统集成，支持生产环境使用

## 配置文件设计

### backtest.conf 结构
```ini
[backtest]
# 回测基础配置
start_date=2023-01-01
end_date=2024-12-31
initial_cash=1000000
benchmark=000001.SH
frequency=1d  # 1d, 1h, 1m, 1s

# 交易成本配置
open_tax=0
close_tax=0.001
open_commission=0.0003
close_commission=0.0003
min_commission=5

# 滑点配置
slippage=0.005
slippage_type=percentage  # percentage, fixed

# 风控配置
max_position_ratio=0.1
max_order_ratio=0.1
enable_t1_rule=true
enable_limit_rule=true

# 数据源配置
data_source=file
cache_enabled=true
preload_data=true

# 策略配置
strategy=DemoStrategy
strategy_params={}

# 适配器配置
adapters=cn_stock,cn_fund
```
