### 1.2 main函数执行流程 (`finhack/finhack/core/command/finhack.py`)
```python
def main():
    """主函数，处理命令行参数并启动框架"""
    # 1. 初始化核心类
    core = Core()

    # 2. 加载模块
    core.load_module()

    # 3. 处理后台运行或直接执行
    if core.args.background:
        # 创建子进程
        pid = os.fork()
        if pid == -1:  # fork失败
            print("创建后台进程失败！")
            sys.exit(1)
        elif pid == 0:  # 子进程
            child_process_action(core)
        else:  # 父进程
            Utils.write_pids(pid)
            # 根据action输出不同提示
            if core.args.action == "stop":
                print("停止后台任务！")
            else:
                print("启动后台任务！")
    else:
        # 前台运行
        core.do_action()
```

### 3.2 参数配置加载机制 (`append_args`)

**参数加载优先级**（从高到低）：

1. **命令行 key=value 参数**（最高优先级）
   - 格式：`finhack trader run cash=100000 strategy=Demo`
   - 通过 `setattr` 直接设置到 args 对象

2. **命令行 --key value 参数**
   - 格式：`finhack trader run --cash 100000`

3. **{module}.conf [args.section]**
   - 当指定 `--section=xxx` 时加载

4. **{module}.conf [args]**
   - 模块特定配置

5. **args.conf [module-vendor-action]**
   - 最具体的配置段

6. **args.conf [module-vendor]**
   - 供应商特定配置

7. **args.conf [module]**
   - 模块级别配置

8. **args.conf [global]**（最低优先级）
   - 全局默认配置

**重要规则**：命令行参数会覆盖配置文件中的同名参数。

```python
def append_args(self):
    # 1. 添加项目路径到sys.path
    sys.path.append(self.project_path)
    sys.path.append(self.project_path + '/data/cache/')

    # 2. 从Config类加载配置
    from finhack.library.config import Config

    args_list = {}
    my_args_group_list = Config.get_section_list('args')
    args, unknown = self.parser.parse_known_args()

    # 3. 处理命令行传递的额外参数（支持 key=value 格式）
    # 示例: finhack trader run cash=100000 strategy=MyStrategy
    cmdline_args = {}
    for arg_str in unknown:
        if '=' in arg_str:
            key, value = arg_str.split('=', 1)
            key = key.lstrip('-')  # 移除开头的 --（如果有）
            cmdline_args[key] = value

    vendor = "default" if args.vendor is None else args.vendor

    # 4. 按优先级加载配置段（命令行参数优先级最高）
    for my_args_group in my_args_group_list:
        if my_args_group == 'global':
            my_args_list = Config.get_config('args', my_args_group)
            for arg, default in my_args_list.items():
                # 只有命令行没有指定时，才使用配置文件的值
                if arg not in cmdline_args:
                    args_list[arg] = default

    # [module] 段 - 模块特定配置
    for my_args_group in my_args_group_list:
        if my_args_group == args.module:
            my_args_list = Config.get_config('args', my_args_group)
            for arg, default in my_args_list.items():
                if arg not in cmdline_args:
                    args_list[arg] = default

    # [module-vendor] 段 - 模块+供应商配置
    for my_args_group in my_args_group_list:
        if my_args_group == args.module + '-' + vendor:
            my_args_list = Config.get_config('args', my_args_group)
            for arg, default in my_args_list.items():
                if arg not in cmdline_args:
                    args_list[arg] = default

    # [module-vendor-action] 段 - 模块+供应商+动作配置
    for my_args_group in my_args_group_list:
        if my_args_group == args.module + '-' + vendor + '-' + args.action:
            my_args_list = Config.get_config('args', my_args_group)
            for arg, default in my_args_list.items():
                if arg not in cmdline_args:
                    args_list[arg] = default

    # 5. 加载模块专用配置文件 {module}.conf
    my_args_list = Config.get_config(args.module, 'args')
    for arg, default in my_args_list.items():
        if arg not in cmdline_args:
            args_list[arg] = default

    # 6. 加载指定section配置
    if args.section is not None and args.section != '':
        my_args_list = Config.get_config(args.module, args.section)
        for arg, default in my_args_list.items():
            if arg not in cmdline_args:
                args_list[arg] = default

    # 7. 添加命令行参数（优先级最高）
    for key, value in cmdline_args.items():
        args_list[key] = value

    # 8. 将配置添加到参数解析器
    for arg, default in args_list.items():
        group = self.parser.add_argument_group(my_args_group)
        group.add_argument('--' + arg, metavar='', default=default)

    # 9. 获取已解析的参数（直接返回，不会重新解析）
    args = self.parse_args()

    # 10. 【关键】手动设置命令行参数到args对象
    # 因为 parse_args 只处理 --key value 格式，不处理 key=value 格式
    for key, value in cmdline_args.items():
        setattr(args, key, value)

    self.args = args

    # 11. 设置全局变量
    import runtime.global_var as global_var
    global_var.args = args
```

### 3.4 Config类实现 (`finhack/library/config.py`)
```python
class Config:
    @staticmethod
    def get_config(config_name, section='default'):
        file_name = config_name + ".conf"
        file_path = CONFIG_DIR + file_name
        config = configparser.ConfigParser()
        config.read(file_path)
        
        # 检查section是否存在
        section_list = Config.get_section_list(config_name)
        if section not in section_list:
            return {}
        
        # 返回配置字典
        config_items = config.items(section)
        config_dict = {key: value for key, value in config_items}
        return config_dict
    
    @staticmethod
    def get_section_list(config_name):
        file_name = config_name + ".conf"
        file_path = CONFIG_DIR + file_name
        config = configparser.ConfigParser()
        config.read(file_path)
        return config.sections()
```

```python
def load_module(self):
    module = self.args.module
    # 1. 构建模块loader路径
    module_loader_path = "finhack.core.loader." + self.args.module + "_loader"
    class_name = module.capitalize() + "Loader"
    action = self.args.action
    
    # 2. 构建用户自定义loader路径
    user_module_path = self.project_path + '/loader/' + self.args.module + "_loader.py"
    
    # 3. 通过ClassLoader加载模块
    module = ClassLoader.get_module(module_path=module_loader_path, user_module_path=user_module_path)
    self.module = module
    
    # 4. 确定类名
    if "base_loader.py" == os.path.basename(inspect.getfile(module)):
        self.class_name = 'BaseLoader'
    else:
        self.class_name = class_name
    
    self.action = action
```

### 4.2 ClassLoader实现 (`finhack/core/loader/class_loader.py`)

```python
class ClassLoader:
    """类加载器 - 用户模块优先"""

    @staticmethod
    def get_module(module_path='', user_module_path=''):
        """
        加载模块：用户优先 → 系统 → 报错（抛出异常，不回退）
        """
        # 延迟导入 Log，避免循环导入
        try:
            import finhack.library.log as Log
            logger = Log.logger
        except Exception:
            logger = None

        # 1. 优先加载用户自定义模块
        if user_module_path and os.path.exists(user_module_path):
            filename = os.path.basename(user_module_path)
            module_name = "user_module"
            if filename.endswith(".py"):
                module_name = filename[:-3]
            try:
                module_spec = importlib.util.spec_from_file_location(module_name, user_module_path)
                module = importlib.util.module_from_spec(module_spec)
                module_spec.loader.exec_module(module)
                if logger:
                    logger.debug(f"成功加载用户模块: {user_module_path}")
                return module
            except Exception as e:
                if logger:
                    logger.error(f"加载用户模块失败: {user_module_path}, 错误: {e}")
                import traceback
                traceback.print_exc()
                raise  # 【重要】抛出异常，不回退

        # 2. 加载系统模块
        elif module_path:
            try:
                module = importlib.import_module(module_path)
                if logger:
                    logger.debug(f"成功加载系统模块: {module_path}")
                return module
            except ModuleNotFoundError as e:
                if logger:
                    logger.critical(f"模块不存在: 用户路径={user_module_path}, 系统路径={module_path}")
                import traceback
                traceback.print_exc()
                raise  # 【重要】抛出异常，不回退

        # 3. 两者都不存在
        else:
            if logger:
                logger.critical("module_path 和 user_module_path 均未提供")
            raise ValueError("必须提供 module_path 或 user_module_path")
```

### 4.3 BaseLoader实现 (`finhack/core/loader/base_loader.py`)

```python
class BaseLoader:
    def __init__(self, args):
        # 1. 处理后台运行
        if args.background:
            self.background(args)

        # 调试：打印接收到的参数
        import logging
        logger = logging.getLogger(__name__)
        logger.info(f"[BaseLoader] 接收到的args.__dict__: {args.__dict__}")

        self.args = args
        self.module_name = args.module
        self.vendor = "default" if self.args.vendor is None else self.args.vendor

        if args.action == "stop":
            return

        # 2. 构建模块路径
        self.module_path = f"finhack.{self.module_name}.{self.vendor}.{self.vendor}_{self.module_name}"
        self.user_module_path = f"{BASE_DIR}/{self.module_name}/{self.vendor}/{self.vendor}_{self.module_name}.py"

        # 3. 加载模块
        self.module = ClassLoader.get_module(module_path=self.module_path, user_module_path=self.user_module_path)
        Log.logger.debug(f"module_path:{self.module_path}")
        Log.logger.debug(f"user_module_path:{self.user_module_path}")

        # 4. 实例化类（带详细错误处理）
        try:
            Log.logger.debug(f"klass:{self.vendor.capitalize()+self.module_name.capitalize()}")

            # 分步处理：先获取类，再实例化
            class_name = self.vendor.capitalize() + self.module_name.capitalize()

            # 第一步：检查类是否存在
            try:
                klass_type = getattr(self.module, class_name)
                Log.logger.debug(f"成功找到类: {class_name}")
            except AttributeError as e:
                Log.logger.error(f"找不到类 '{class_name}' 在模块 {self.module}")
                Log.logger.error(f"模块中可用的类和函数: {[name for name in dir(self.module) if not name.startswith('_')]}")
                raise AttributeError(f"模块 {self.module.__name__} 中不存在类 '{class_name}'") from e

            # 第二步：尝试实例化类
            try:
                self.klass = klass_type(self.args)
                Log.logger.debug(f"成功实例化类: {class_name}")
            except Exception as e:
                Log.logger.error(f"实例化类 '{class_name}' 时出错: {str(e)}")
                Log.logger.error(f"错误类型: {type(e).__name__}")
                Log.logger.error("类实例化失败，可能的原因:")
                Log.logger.error("1. 类的__init__方法有错误")
                Log.logger.error("2. 类依赖的模块或包未正确导入")
                Log.logger.error("3. 类初始化需要必要的参数但未提供")
                Log.logger.error("完整错误信息:")
                import traceback
                traceback.print_exc()
                raise Exception(f"类 '{class_name}' 实例化失败: {str(e)}") from e
            self.klass.args = self.args
            Log.logger.debug(f"klass object:{self.klass}")

        except AttributeError as e:
            # 输出详细的错误信息和诊断建议
            class_name = self.vendor.capitalize() + self.module_name.capitalize()
            Log.logger.error(f"类 '{class_name}' 不存在")
            Log.logger.error(f"模块路径: {self.module_path}")
            Log.logger.error(f"用户模块路径: {self.user_module_path}")

            if hasattr(self.module, '__file__'):
                Log.logger.error(f"实际加载的模块文件: {self.module.__file__}")

            module_file_path = self.module_path.replace('.', '/') + ".py"
            if not os.path.exists(module_file_path) and not os.path.exists(self.user_module_path):
                Log.logger.error(f"模块文件均不存在:")
                Log.logger.error(f"  - 系统模块: {module_file_path}")
                Log.logger.error(f"  - 用户模块: {self.user_module_path}")

            Log.logger.error(f"请检查:")
            Log.logger.error(f"1. 类名是否正确: {class_name}")
            Log.logger.error(f"2. 模块文件是否存在且语法正确")
            Log.logger.error(f"3. 类是否正确定义并导出")
            Log.logger.error(f"4. 包是否正确安装")

            print("完整错误追踪:", file=sys.stderr)
            import traceback
            traceback.print_exc()
            exit()

        except Exception as e:
            # 处理其他类型的异常
            class_name = self.vendor.capitalize() + self.module_name.capitalize()
            Log.logger.error(f"加载类 '{class_name}' 时发生未知错误: {str(e)}")
            Log.logger.error(f"错误类型: {type(e).__name__}")
            Log.logger.error("请检查:")
            Log.logger.error("1. 模块文件语法是否正确")
            Log.logger.error("2. 模块依赖是否完整")
            Log.logger.error("3. 类定义是否正确")

            print("完整错误追踪:", file=sys.stderr)
            import traceback
            traceback.print_exc()
            exit()
```

#### BaseLoader.stop 方法

当 `action="stop"` 时，`__init__` 会直接返回，但 `BaseLoader` 定义了完整的 `stop` 方法用于终止后台进程（约130行实现）。

```python
def stop(self):
    """终止后台进程

    通过以下方式终止进程：
    1. 通过 PID 文件终止进程
    2. 通过进程名兜底终止进程
    3. 递归终止子进程
    """
    if global_var.args.vendor != None:
        pids_path = os.path.join(BASE_DIR, "data/cache/runtime",
                                f"{global_var.module_name}_{global_var.args.vendor}.pids")
        process_name_pattern = f"{global_var.module_name}_{global_var.args.vendor}"
    else:
        pids_path = os.path.join(BASE_DIR, "data/cache/runtime",
                                f"{global_var.module_name}.pids")
        process_name_pattern = f"{global_var.module_name}"

    # 1. 通过PID文件终止进程
    fall_list = ""
    pid_terminated = False

    if os.path.exists(pids_path):
        with open(pids_path, "r") as f:
            for line in f:
                try:
                    pid = int(line.strip())
                    if psutil.pid_exists(pid):
                        parent = psutil.Process(pid)
                        # 先终止子进程
                        children = parent.children(recursive=True)
                        for child in children:
                            child.terminate()
                        parent.terminate()
                        pid_terminated = True

                        # 等待进程终止
                        time.sleep(1)
                        if psutil.pid_exists(pid):
                            parent.kill()  # 强制终止
                except Exception as e:
                    Log.logger.error(f"终止进程 {pid} 时出错: {e}")

    # 2. 通过进程名兜底终止
    terminated_by_name = False
    for proc in psutil.process_iter(['pid', 'name', 'cmdline']):
        try:
            cmdline = " ".join(proc.info.get('cmdline', []))
            if ("python" in cmdline.lower() and
                global_var.module_name in cmdline and
                "finhack" in cmdline):
                proc.terminate()
                terminated_by_name = True
        except:
            continue

    # 输出结果
    if pid_terminated or terminated_by_name:
        Log.logger.info("停止任务成功！")
    else:
        Log.logger.info("未找到需要停止的进程")
```

## 5. 执行流程

### 5.1 动作执行 (`do_action`)
```python
def do_action(self):
    # 1. 获取Loader类
    loader = getattr(self.module, self.class_name)
    loader_obj = loader(self.args)
    
    # 2. 检查Loader是否有对应的action方法
    if hasattr(loader_obj, self.action):
        method = getattr(loader_obj, self.action)
    else:
        # 3. 如果Loader没有，则从业务类中获取action方法
        klass = loader_obj.klass
        klass.args = self.args
        method = getattr(klass, self.action)
    
    # 4. 执行方法
    method()
```

## 6. 全局变量和运行时系统

### 6.1 全局变量初始化 (`generate_global`)
```python
def generate_global(self):
    import runtime.global_var as global_var
    
    # 1. 设置进程ID
    global_var.pid = os.getpid()
    
    # 2. 生成参数哈希
    arg_vars = vars(global_var.args).copy()
    arg_vars['background'] = None
    hash = Utils.md5(str(arg_vars))
    global_var.hash = hash
    
    # 3. 设置模块和动作名称
    global_var.module_name = global_var.args.module
    global_var.action_name = global_var.args.action
```

## 7. 日志系统初始化

### 7.1 日志初始化 (`init_logger`)
```python
def init_logger(self):
    from runtime.constant import LOGS_DIR

    vendor = "default" if self.args.vendor is None else self.args.vendor
    action = "run" if self.args.action is None else self.args.action

    # 【重要】从参数中获取日志级别，默认为INFO
    log_level = getattr(self.args, 'log_level', 'INFO') \
                if hasattr(self.args, 'log_level') else 'INFO'

    Log.logger = Log.Log(
        module=self.args.module,
        vendor=vendor,
        action=action,
        logs_dir=LOGS_DIR,
        background=self.args.background,
        level=log_level  # 传入日志级别
    ).logger
```

## 8. 命令执行示例

### 8.1 完整命令执行流程示例
以命令 `finhack trader run --vendor=qmt --project_path=/path/to/project` 为例：

1. **命令行解析**：
   - module: trader
   - action: run
   - vendor: qmt
   - project_path: /path/to/project

2. **Core初始化**：
   - 设置project_path
   - 加载help.conf
   - 生成基础参数解析器
   - 检查环境和项目
   - 刷新运行时文件

3. **配置加载**：
   - 加载args.conf中的[global]段
   - 加载args.conf中的[trader]段
   - 加载args.conf中的[trader-qmt]段
   - 加载args.conf中的[trader-qmt-run]段（如果存在）
   - 加载trader.conf中的[args]段
   - 重新解析所有参数

4. **模块加载**：
   - 尝试加载用户自定义：`/path/to/project/loader/trader_loader.py`
   - 如果不存在，加载系统：`finhack.core.loader.trader_loader`
   - 如果都不存在，抛出异常（不会自动回退到base_loader）

5. **业务模块加载**：
   - 在Loader中加载业务模块：`finhack.trader.qmt.qmt_trader`
   - 或用户自定义：`/path/to/project/trader/qmt/qmt_trader.py`
   - 实例化QmtTrader类

6. **执行动作**：
   - 检查TraderLoader是否有run方法
   - 如果没有，从QmtTrader类中获取run方法
   - 执行run方法开始交易

## 9. 扩展机制

用户可以在项目的loader目录下创建自定义Loader：

```python
# /path/to/project/loader/trader_loader.py
from finhack.core.loader.base_loader import BaseLoader

class TraderLoader(BaseLoader):
    def run(self):
        # 自定义运行逻辑
        trader = self.klass
        trader.args = self.args
        trader.run()
    
    def custom_action(self):
        # 自定义动作
        print("执行自定义动作")
```

## 10. 错误处理机制

### 10.1 模块加载失败处理
- 如果用户模块存在但加载失败，显示详细错误信息并**抛出异常**
- 如果系统模块不存在，显示错误信息并**抛出异常**（不会自动回退到base_loader）
- 如果类不存在，显示可用类列表并退出

### 10.2 配置文件错误处理
- 配置文件不存在时使用默认值
- 配置项缺失时返回空字典
- 配置文件语法错误时显示错误位置

## 11. 性能优化

### 11.1 模块延迟加载
- 只有在需要时才加载具体的业务模块
- 配置文件采用按需加载机制

### 11.2 缓存机制
- 运行时常量文件缓存
- 配置文件解析结果缓存

## 12. 总结

FinHack框架采用了高度模块化和可扩展的设计：

1. **分层架构**：命令行入口 → Core → Loader → 业务模块
2. **配置驱动**：多层级配置文件系统，支持灵活的参数组合
3. **插件机制**：用户可以自定义Loader和业务模块
4. **运行时系统**：动态生成运行时常量和全局变量
5. **错误处理**：完善的错误处理和回退机制

这种设计使得框架既保持了核心功能的稳定性，又提供了高度的可扩展性和灵活性。
