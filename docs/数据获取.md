# 数据获取Collector系统详细分析

## 整体架构概述

Finhack框架的数据获取系统采用分层架构设计，通过Tushare API实现金融数据的自动化收集与管理。整个系统以**TushareCollector**为核心控制器，协调各个专用数据收集模块，实现多线程并发数据获取。

### 核心组件结构

├── baseCollector.py          # 基础收集器类（目前为空，预留扩展）

#### 2.2 分步骤数据收集流程

1. **第一步：基础数据**

   - 股票名称变更（astock_namechange）
   - 沪深港通成分股（astock_hs_const）
   - 上市公司基本信息（astock_stock_company）

2. **第二步：价格数据**（依赖于股票基本信息）

   - 周线行情（weekly）
   - 月线行情（monthly）
   - 复权因子（adj_factor）
   - 停复牌信息（suspend_d）
   - 每日指标（daily_basic）
   - 资金流向（moneyflow）
   - 涨跌停价格（stk_limit）
   - 涨跌停股票（limit_list）

3. **第三步：财务数据**（依赖于财务披露日期）

   - 美国宏观经济指标

9. **第九步：其他数据**
   - 新闻联播文字稿（cctv_news）

10. **第十步：期货数据**
    - 期货基本信息（fut_basic）

## 性能优化策略

### 1. 并发控制

- 最大并发线程数：20
- 指数收集：3线程
- 财务数据筛选：3线程
- 数据导出：10线程

### 2. 内存管理

- 分批处理：chunksize=5000（动态调整）
- 显式创建DataFrame副本：`.copy()`
- 及时释放内存：`del df` + `gc.collect()`

### 3. 缓存策略

- 检查点机制避免重复获取
- 历史年份数据只处理一次
- 临时表+替换模式避免脏数据
